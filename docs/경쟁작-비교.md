## 1. 비교 기준 — 우리 게임의 축 (기획서 기준)

1. 2D 탑뷰, **싱글 PvE 익스트랙션** (죽으면 들고 나간 것 전부 손실)
2. **장비가 기본 동작까지 바꾼다** — 한 캐릭터로 여러 클래스 (TF2의 마법 버전에서 출발)
3. **무기 + 마법 하이브리드** 빌드
4. 핫라인 마이애미식 **속도감** + 헬다이버즈식 **몰려오는 적**
5. 영구 성장 (레시피 해금, 기지 시설, 보관함)
6. 대상: 익스트랙션이 낯선 사람

## 3. 관찰 (AI 분석)

1. **수요는 증명됐다.** 탑뷰 싱글 PvE 익스트랙션은 Duckov(300만 장)와 ZERO Sievert(약 65만 장)가 성공한 장르다. 누나 질문 "왜 사람들이 원할 거라 생각했나"에 숫자로 답할 수 있다.
2. **대신 자리가 붐빈다.** Duckov가 같은 자리를 크게 선점했다. "탑뷰 싱글 익스트랙션"만으로는 차별점이 되지 않는다.
3. **기존 강자는 총기 중심이다.** Duckov와 ZERO Sievert의 강점은 총기와 개조다. 마법 중심이나 하이브리드는 드물다.
4. **가장 위험한 경쟁작은 33 Days till Extraction이다.** 무기 + 마법 + 탑뷰 + 기지 + 부활까지 콘셉트가 많이 겹친다. 아직 규모는 작지만 우리 출시 시점에는 커져 있을 수 있다. 직접 확인이 필요하다.
5. **클래스 고정 vs 장비로 클래스 변경.** Dark and Darker는 클래스를 고르면 고정된다. "한 캐릭터가 장비로 여러 클래스가 된다"는 점은 비교작에서 뚜렷하게 보이지 않았다.
