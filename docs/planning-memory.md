# Dust Scrapper 작업 기억 (에이전트용)

기획의 기준은 [기획서.md](기획서.md) 하나다. 이 파일은 작업 방식, 진행 단계, 결정 이력만 담는다. 규칙·수치는 여기에 중복해서 쓰지 않는다.

## ▶ 다음 세션 시작점 (2026-10-18 마지막 갱신 — 랜턴 1차 끝, **다음 세션은 맵**)

**다음 세션: 맵 (사용자 2026-10-18 "다음 세션에서 맵에 대해서 진행하자")**
- 방향은 2026-10-16에 정함: 무작위 2단계(바깥·배치는 생성, 건물은 손으로 만든 것을 뽑아 배치, 건물 안 물건·적은 유형별로 비슷하게 매번 다름). AI 구조 계획은 아래 "2026-10-16 맵 시스템 방향"(`BuildingPiece`·`EnemySpot`·`BuildingType`·`MapLayout`/`LotSlot`·`MapGenerator`·`PropScatter`, 첫 범위 ①②③).
- 시작할 때 할 일: 사용자가 맵 구조·밸런스를 그림·표·말로 알려 주면, 그 설명에 맞춰 위 구조 계획을 고쳐 말하고 동의받은 뒤 구현. AI가 먼저 큰 계획표를 내밀지 않는다(사용자 그림에서 출발).
- 같이 정해야 할 것(빈칸): 건물을 타일맵으로 바꿀지(AI 추천: 바꿈), 맵 3~5개의 테마, 맵 사이 이동, 버티기 탈출을 남길지, 맵이 매번 바뀌면 "탈출구 외우기"가 안 맞는 문제(2026-10-16 AI가 찾음, 사용자 확인 전).
- 작업 원칙(2026-10-18 사용자 동의): 규칙(재미)이 먼저, 설정은 설명하는 쪽 — 설정은 기본 `잠정`, 설정 충돌로 작업을 멈추지 않는다(AGENTS.md 기획 항목).
- **2026-10-19 (맵 전에 사용자가 먼저 꺼냄)**: ① 이야기 — 글로우 가스 속에서 귀중한 자원(미정)을 얻으려고 **특수 랜턴**(정화기 겸 순간이동기, 항상 지님, 가방 같은 역할, 전투용 랜턴과 다름)을 쓴다. 자원을 얻으면 다음 자원 쪽으로 순간이동 = 다음 스테이지, 정화엔 제한 시간, 가스 노출 = 글로우병, 죽으면 특수 랜턴을 잃음, 최종 목표 = 랜턴에 자원을 모두 채우기. 기획서 2절·3절 "특수 랜턴". 같은 날 사용자 답: 귀중한 자원 = **특수 마법석**, 스테이지 = 맵 하나, 순간이동은 큰 소리(거치식 = 버티기처럼 / 들고 다니는 식 = 잠시 뒤, 미정), 정화 제한 시간 = **스테이지 시간**(끝나면 글로우병 오름, 다음 맵에서 다시 참), 맵 3~5개 뒤 **거대 보스 → 매우 특수한 마법석 + 기지 복귀**, 죽으면 다 잃고 새 랜턴으로 다시(기지에 맡긴 건 남음), **루프(리바이버)는 그대로**. AI가 처음에 루프·결말을 문제 삼아 사용자가 "이해 제대로 하고 있는 거 맞아?"라고 지적함. **맵 작업은 이 구조(맵 = 특수 마법석 하나 + 스테이지 시간 + 순간이동 출구)를 바탕으로 한다.** ② 도트 — 머리·어깨·팔·발을 모두 따로(두손 무기는 어깨를 시계방향으로, 권총은 팔 길게, 스태프는 팔 짧게). 기획서 1절·3절 쥐는 모습.
